# Litmus Test & Group Classification - 2D Science Animation

An animated chemistry explanation demonstrating how litmus paper indicators identify Acidic (Group A), Basic (Group B), and Neutral (Group C) solutions.

## 📌 Topic Covered
- **Group A:** Blue Litmus → Red (**Acidic**)
- **Group B:** Red Litmus → Blue (**Basic**)
- **Group C:** No Color Change (**Neutral**)
